# 용산 IMAX 듄 파트 3 — v1.5 Relay 가설 검증 (기본 7~10초 랜덤)

## 목적
2026-12-21 예매가 열리기 전 Relay의 HTTP 502가 발생하던 현상이 실제 오픈 시 HTTP 200과 IMAX 회차로 전환되는지 검증하는 1회성 실험입니다. 502를 미오픈으로 해석하지 않습니다. 실시간 조회 성공을 보장하지 않습니다.

## 배포
기존 실행 중인 감시 서비스를 중지한 후, ZIP을 풀어 GitHub 저장소 최상위 파일을 전체 교체하고 Commit/Deploy 합니다. Dockerfile, monitor.mjs, probe.mjs, parser.mjs, verify_local_imports.mjs, package.json, railway.json을 반드시 포함합니다. Railway Variables의 TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID는 그대로 사용합니다. 이전 날짜/속도/직접 호출/캐시버스트 변수는 사용하지 않습니다. 이전 v1.4 종료 상태를 유지하여 이미 완료된 테스트를 다시 시작하지 않습니다. Railway 서비스 Settings의 Restart Policy가 Never인지 확인합니다. 자동 종료 후 재시작되지 않도록 합니다.

## 동작
- 대상: 2026년 12월 21일 CGV 용산(0013) 듄3(30001790) IMAX. Relay의 상영관 정보가 없는 경우 624석을 근거로 판단합니다.
- 기존 사용자 테스트와 동일한 공개 Relay URL의 일반 요청만 사용합니다. 기본 7~10초 랜덤 간격. 502 등 연속 조회 불가 1~2회: 7~10초, 3~4회: 60~90초, 5회 이상: 180~300초. 정상 응답 시 연속 실패 횟수를 초기화하여 7~10초로 복귀. 더 긴 Retry-After는 항상 존중합니다. 직접 CGV 요청 없음, 캐시 무효화 없음.
- 502/연결 실패/비정상 데이터: UNKNOWN으로 로그만 기록하며 다음 간격에 확인합니다. 이는 미오픈 확인이 아닙니다.
- 200 정상 응답에 IMAX 없음: NO_IMAX, 조회는 성공했으나 오픈 회차 확인 못함.
- 200 정상 응답에 IMAX 있음: OPEN, Telegram 알림 1회 후 종료. 이후 날짜는 감시하지 않습니다(첫 성공 후 가설 검증 결과를 바탕으로 별도 결정).
- 401/403/429/451 또는 재시도 불가 응답(상위 응답 상태 포함): STOP, 추가 요청 없이 종료하고 알림.
- 12월 21일 00:00 KST까지 유효. 그 시각 전에 결과가 없으면 자동 종료합니다.
- 기본 시작/502 Telegram 알림 없음. 정상 응답/실패는 Railway Deploy Logs에서 확인. Telegram 발송 오류 시 OPEN_PENDING_ALERT 로그와 상태 파일로 확인할 수 있습니다. 재배포 간 결과 보존을 원하면 /data에 Railway Volume을 연결합니다. 저장된 종료 상태가 존재하면 추가 조회하지 않습니다.

## 한계
공개 Relay에 새 시간표가 실제로 반영되지 않을 수 있습니다. 캐시 갱신 지연과 연속 오류 시 재시도 간격 증가로 오픈 직후 알림은 보장하지 않습니다. 공식/정상 알림을 병행하세요. 실제 Relay/CGV/Telegram 네트워크 테스트 및 Railway Docker 이미지 빌드는 수행하지 않았습니다. Node 테스트는 사용자 제공 응답과 모의 응답으로 검증합니다.
